## Guia Rápido de Diagramação (Identidade Método Construindo Pontes)
- **Formato:** A4 vertical (`210 x 297 mm`), margens confortáveis para leitura no celular e impressão.
- **Paleta:** Azul Noite (`#020B3A`) para títulos, Azul Cobalto (`#052A83`) para cabeçalhos de bloco, Azul Elétrico (`#0878F9`) para ícones e setas, Ciano (`#17DDF2`) para destaques de "Dica de Prova", Fundo Claro (`#F4F7FF` / `#FFFFFF`) para leitura limpa e econômica na impressão.
- **Tipografia:** Montserrat (ExtraBold nos títulos, Regular/Medium nos blocos).
- **Estrutura padrão por página visual:** Cabeçalho do Módulo -> Conceito Central -> Esquema em 3 a 4 passos -> Quadro **"Base Legal"** (artigos do ECA) -> Quadro **"Dica de Prova"**.
